02 / The boundaries

One model. Clear responsibilities.

The Workshop keeps mathematical meaning separate from runtime composition, execution authority, storage and presentation.

NeuralNetworks

Owns model topology, tensors, operations, numerical semantics, bounded evaluation and execution evidence.

DataWarehouse

Owns storage allocation, shelves, handles, liveness, dirty tracking and storage lifetime. NeuralNetworks owns the meaning of its data.

FSM_COS / FSM_Execution

FSM_COS composes capabilities. FSM_Execution owns execution lifecycle and scheduling. Neither replaces neural graph semantics.

Hermit

Owns goals, observations, planning, policy and permissions. It may request bounded computation; it does not delegate authority to model output.

GPU backend

Will implement declared backend-neutral semantics. Device, precision, transfers, synchronization and fallback must remain observable.

Visualize

Will present actual execution evidence and traces. It must not recompute neural values to create a convincing picture.

03 / Honest progress

Build the proof, then scale it.

The architecture is deliberately GPU-first, not GPU-only. Correctness and observable evidence come before acceleration claims.

Documented

Model and execution contracts

Proposed DAG, tensor, numerical, bounded-work and trace contracts, with a hand-checkable acceptance fixture.

Awaiting owner acceptance

First inference implementation

The MVP decisions remain proposed. No CPU inference evaluator is claimed or started; its explicit acceptance gate remains in place.

Future / hardware-dependent

Accelerated backend

Select a GPU API only after target hardware and runtime reconnaissance. No silent CPU fallback and no unmeasured acceleration claims.
